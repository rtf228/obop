## 🌟 Структура та особливості сайту

1. **Головна (Hero):**
   - Заголовок: *«Приміряй майбутнє онлайн»*.
   - Короткий опис сервісу та кнопки переходів: «Спробувати примірку» і «Для магазинів».
   - Ключові метрики: *3 сек* генерація, *98%* точність розміру, *-38%* повернень товарів.

2. **Віртуальна примірочна (Декоративний макет інтерфейсу):**
   - **Місце для завантаження фото:** стилізована зона Drag & Drop / вибору файлу з попереднім переглядом та можливістю видалити фото.
   - **Каталог для декору:** картки одягу з фотографіями, цінами у гривнях (₴), фільтрами за категоріями та вибором розміру (XS, S, M, L, XL).
   - **Кнопка «Приміряти образ»:** декоративна кнопка з модальним поясненням про демо-режим концепту.
   - **Чесне маркування:** чітке повідомлення про демонстраційний режим інтерфейсу.
   - **Захист даних:** чекбокс згоди на обробку фото відповідно до вимог приватності.

3. **Як це працює:**
   - 3 послідовні кроки: *Завантаж фото* → *Обери одяг* → *Переглянь результат*.

4. **Переваги:**
   - Зручний вибір одягу без черг, персоналізація стилю, економія часу та коштів.

5. **Для бізнесу (B2B):**
   - Скорочення повернень на 38%, ріст конверсії на 24%, готова інтеграція для Shopify, WooCommerce, OpenCart та REST API.

6. **Тарифи (в гривнях ₴):**
   - **Старт** — 2 490 ₴/міс (для невеликих бутиків і шоурумів).
   - **Прогрес** — 6 890 ₴/міс (найпопулярніший, для онлайн-магазинів).
   - **Enterprise** — 17 900 ₴/міс (для модних брендів і ритейлерів).

7. **Часті запитання (FAQ):**
   - Інтерактивний акордеон із відповідями про точність розмірів, безпеку фото (GDPR) та підключення сайту.
